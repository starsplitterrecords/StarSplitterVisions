# Star Splitter Records — Authorship & Lineage

This branch adds the listener-facing authorship and provenance framework to the Records site without altering the Star Splitter Visions application.

## Public structure

- Every artist page has a **Role in the catalog** statement.
- Every artist page has a separate **Authorship & process** statement.
- Every release has a dedicated page.
- Project-level provenance appears on associated release pages.
- Release-specific lineage remains hidden until completed and approved in the CMS.

## Release provenance fields

- composition origin
- lyrics
- arrangement
- instrumentation
- vocals
- AI role
- source work
- version of
- related releases
- notes

## Listener-facing principle

The site does not reduce the catalog to a single “AI music” label. It explains who originated the work, what was transformed, how it was realized, and who made the final creative decisions.

## Source package

The complete verified implementation is preserved in `Star_Splitter_Records_Authorship_Lineage_CMS_v2.zip` from the working session. This branch records the final approved copy framework and schema so subsequent implementation work has a durable GitHub baseline.
