# Published Asset Manifests

This folder preserves manifest records for assets that have moved from intake into canonical runtime locations.

Runtime code should not reference files in this folder.

Manifest names should match the published asset or batch purpose when practical.

Example:

```text
2026-05-12-test-upload-check.txt
azure-reach-issue-01-cover.txt
vikings-2026-issue-01-pages-001-015.txt
```
